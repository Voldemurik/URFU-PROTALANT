LinuxCNC выбран как открытая система ЧПУ с публичной технической документацией: установка и настройка, HAL, драйверы, G-code, интерфейсы и справочные материалы. Это первый реальный документ для проверки загрузчика и поиска, а не замена документации партнёра.

### Версия и происхождение

- Официальный индекс: <https://linuxcnc.org/docs/2.9/html/>.
- Исходный PDF: <https://linuxcnc.org/docs/2.9/pdf/LinuxCNC_Documentation.pdf>.
- Дата скачивания: 25.10.2026.
- Веб-индекс на дату скачивания обозначен как документация LinuxCNC 2.9.10.
- Метаданные самого PDF: `LinuxCNC V2.9.7-9-gd435482ad1, 22 Oct 2025`; дата создания PDF — 15.12.2025. Поэтому локальный файл назван по ветке `2.9`, без присвоения ему версии 2.9.10.
- SHA-256: `996de93388aea13fe5aebd232d6641410255d83f2df6f74755431e8a3196f5f2`.

Машиночитаемые сведения и контрольная сумма сохранены в [`data/corpus/manifest.json`](../data/corpus/manifest.json).

## Права на использование

На PDF-странице 1334 указано разрешение копировать, распространять и изменять документацию по GNU Free Documentation License 1.1 или любой более поздней версии, без неизменяемых разделов и текстов обложки. Текст лицензии включён в сам PDF. Лицензия документации не заменяет MIT-лицензию кода проекта.

## Проверка пригодности для RAG

- PDF открывается, не зашифрован, содержит 1347 страниц.
- Текст извлекается штатным загрузчиком проекта на всех страницах; пустых по тексту страниц не обнаружено.
- Всего извлечено 2 463 787 текстовых символов до нормализации загрузчиком.
- Оригинальный PDF сохранён без изменений; очистка колонтитулов, таблиц и особенностей вёрстки относится к шагу 2 этапа 2.

Для индексации только этого документа:

```bash
techdoc ingest docs/LinuxCNC_Documentation_2.9.pdf
```

Не следует передавать весь каталог `docs/`: тогда в индекс попадут также служебные Markdown-файлы самого проекта.
