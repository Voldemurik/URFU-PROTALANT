# Как участвовать в проекте

Проект развивается в рамках программы «ПроТалант» УрФУ, но открыт для предложений,
вопросов и pull request'ов.

## Окружение разработчика

```bash
git clone https://github.com/Voldemurik/URFU-PROTALANT.git
cd URFU-PROTALANT
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -e ".[dev,faiss]"
```

Проверки, которые запускает CI (автоматическая проверка на GitHub при каждом push в `main` и в pull request):

```bash
ruff check .        # стиль и типичные ошибки
pytest              # тесты — работают без Ollama и без GPU
```

## Правила

- **Ветки и коммиты.** Одна задача — одна ветка (`feature/hybrid-rerank`, `fix/pdf-encoding`).
  Сообщение коммита в повелительном наклонении: «Добавить ранжирование…», «Исправить…».
- **Тесты.** Новая логика поиска, чанкинга или метрик сопровождается тестом в `tests/`.
  Тесты не должны требовать сети или моделей — используйте `HashingEmbedder` и `FakeLLM`.
- **Метрики.** Любое изменение, влияющее на качество ответов (промпт, чанкинг, поиск, модель),
  сопровождается результатом `techdoc eval` до и после — в описании PR.
- **Документация партнёров** никогда не попадает в репозиторий: кладите её в `data/private/`
  (папка в `.gitignore`).

## Структура кода

| Модуль | За что отвечает |
|---|---|
| `loaders.py` | чтение TXT/MD/PDF/DOCX |
| `chunking.py` | структурное разбиение на фрагменты |
| `embeddings.py`, `llm.py` | интерфейсы моделей и их реализации (Ollama, заглушки) |
| `vector_store.py`, `lexical.py`, `retriever.py` | векторный индекс, BM25, гибридный поиск |
| `prompts.py`, `rag.py` | промпты и сам пайплайн «вопрос → ответ со ссылками» |
| `evaluation/` | метрики, LLM-судья, прогон оценочного набора |
| `cli.py` | команды `techdoc …` |
