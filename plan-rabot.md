**Программа:** «ПроТалант» УрФУ, трек «Цифровое производство: промышленный ИИ, цифровые двойники и робототехника»
**Период:** 05.10.2026 – 25.01.2027 (до конца первого этапа программы)
**Промежуточная защита:** 26–29.01.2027
**Принцип:** недели считаются с понедельника по воскресенье (например, 04.01 – 10.01, 11.01 – 17.01, 18.01 – 24.01); каждый этап и шаг занимает целое число недель, стык к стыку. Каждая неделя заканчивается отчётным результатом (замер, код или документ).

## Этап 1. Запуск системы на реальной модели и приведение репозитория в порядок

**Начало:** 05.10.2026 | **Окончание:** 18.10.2026

**Описание:** Первый полный прогон пайплайна (индексация > вопрос > ответ со ссылками > оценка) с настоящей LLM через Ollama вместо офлайн-заглушек. Параллельно — техническая гигиена репозитория: описание и topics на GitHub, бейджи, релиз v0.1.0, унификация целевой модели между README и контуром дообучения, проверка quickstart на чистой машине.

**Ожидаемый результат:** работающая end-to-end система с реальными метриками, воспроизводимая одной командой по README.

**Планируемый артефакт:** релиз v0.1.0 на GitHub + заполненная первая строка таблицы метрик в `docs/evaluation.md` (ссылка на репозиторий).

**Шаги:**

| № | Шаг                                                                                                                                                                | Сроки         |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- |
| 1 | Гигиена репозитория: описание и topics на GitHub, бейджи в README, тег и релиз v0.1.0                                                                              | 05.10 – 11.10 |
| 2 | Установка Ollama, проверка тегов моделей, первый живой прогон `doctor > ingest > ask`, полный `eval --judge`, первая строка реальных метрик в `docs/evaluation.md` | 12.10 – 18.10 |

## Этап 3. Повышение качества поиска и обработки PDF

**Начало:** 09.11.2026 | **Окончание:** 06.12.2026

**Описание:** Четыре измеримых улучшения, каждое с замером «до/после»: морфология для BM25 (pymorphy3), номера страниц PDF в ссылках на источники, переранжирование кросс-энкодером (`qwen3-reranker`), подбор параметров разбиения (chunk\_size/top\_k) по сетке экспериментов.

**Ожидаемый результат:** рост recall\@k и MRR по сравнению с бейзлайном, ссылки в ответах ведут на конкретную страницу документа.

**Планируемый артефакт:** код улучшений + таблица «до/после» по каждому эксперименту в `docs/evaluation.md` (по сути — мини-исследование, основа отчёта).

## Этап 4. Сравнение моделей, антигаллюцинации, открытый бенчмарк

**Начало:** 07.12.2026 | **Окончание:** 10.01.2027

**Описание:** Сравнение генеративных моделей (qwen3.5:9b/4b, gemma4, granite4.2:3b, gpt-oss:20b) и эмбеддингов (bge-m3 vs qwen3-embedding vs GigaEmbeddings) на единой системе оценки. Борьба с галлюцинациями: промпт-инжиниринг и второй проход проверки, цель — рост trap\_refusal\_rate без роста false\_refusal\_rate. Оформление оценочного набора как открытого русскоязычного бенчмарка промышленной техдокументации (100+ вопросов, лицензия, протокол).

**Ожидаемый результат:** сводная таблица сравнения моделей, измеримо сниженная доля галлюцинаций, опубликованный бенчмарк 100+ вопросов — уникальный вклад проекта.

**Планируемый артефакт:** публичный датасет-бенчмарк с README и протоколом оценки + сводная таблица моделей в репозитории.
