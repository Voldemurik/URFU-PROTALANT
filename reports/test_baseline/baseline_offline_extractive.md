# Отчёт: офлайн-бейзлайн (HashingEmbedder + экстрактивный ответ, без LLM)

Сгенерировано командами:

```bash
techdoc ingest data/sample_docs --offline
techdoc eval data/eval/sample_qa.jsonl --offline --report-md reports/baseline_offline_extractive.md
```

Дата: 2026-08-28. Конфигурация — значения по умолчанию (top_k=5, chunk_size=900, hybrid=true).

## Эксперимент: индексировать ли заголовки

Первая версия индексировала только текст фрагмента. Добавление к индексируемому тексту
названия документа и раздела (`Chunk.index_text()`) дало заметный прирост на том же наборе —
вопросы часто содержат имя оборудования («ПЛК-200», «ФС-400») или раздела, которых в самом
фрагменте нет:

| Метрика | Только текст | Текст + заголовки |
|---|---|---|
| `retrieval/mrr` | 0.909 | **1.000** |
| `answer/must_include` | 0.455 | **0.682** |
| `citations/precision` | 0.818 | **1.000** |
| `citations/recall` | 0.773 | **0.955** |
| `hallucination/trap_refusal_rate` | 0.000 | 0.000 |

Отказы на ловушках по-прежнему 0.000: экстрактивный бейзлайн не умеет молчать — это задача LLM.
