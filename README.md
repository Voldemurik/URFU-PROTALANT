# URFU-PROTALANT
Реализация проекта программы выявления и поддержки талантливых первокурсников Уральского Федерального Университета 2026-2027
# Локальный LLM-ассистент по технической документации

Проект в рамках программы «ПроТалант» УрФУ, 2026–2027.
Трек: «Цифровое производство: промышленный ИИ, цифровые двойники и робототехника».

## Идея
Локальная система вопросов-ответов по технической документации на базе
открытой LLM: RAG-пайплайн на векторном поиске, дообучение через LoRA и
собственная система оценки качества ответов (точность, полнота, доля
галлюцинаций, корректность ссылок на источники). Работает полностью
внутри контура — данные не уходят в облако.

## Индивидуальные достижения
Участие во Всероссийской олимпиаде школьников с 4 по 11 классы на школьном и муниципальном этапах по математике, олимпиадные кружки (курсы) на базе СУНЦ УрФУ по информатике и математике 9-11 классы, уровень английского языка B1 Preliminary Exam Cambridge, дважды высокобалльник (90+) ЕГЭ по профильным предметам, участие в олимпиаде Изумруд (2025/2026 учебный год) с проходом в очный этап по профильным предметам, участие в Пик-IT (2025 год), уверенное владение Python
